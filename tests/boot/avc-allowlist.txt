# One entry per line, whitespace-separated, all five columns required:
#   <source context>  <target context>  <class>  <permission>  <upstream link>
# A denial is KNOWN only if its exact (scontext, tcontext, tclass, permission) tuple is listed.
# Denials with several permissions ({ read open }) must have every permission listed.
